# Iris Flower Classification

## Objective
To classify iris flowers into Setosa, Versicolor, and Virginica using Machine Learning.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Model Used
Logistic Regression

## Results
Achieved ~97-100% accuracy on test data.

## Conclusion
The model successfully classifies iris species based on input features.
